## 0. 코드 작성 원칙

**누가 읽어도 바로 이해되는 코드**를 목표로 한다. 기준은 지금까지 수업에서 직접 만든 코드다.
(2D: Merge Game·Mini Defence, 3D: Mini Golf·AirPlane Game·FPS Game, XR: Throw Physics)

**수업 코드에서 그대로 가져오는 패턴**

| 패턴 | 수업에서 쓴 곳 | 이 프로젝트에서 쓰는 곳 |
| --- | --- | --- |
| 약식 싱글톤 `public static X Instance;` + `Awake`에서 지정 | `MergeGameManager` | `GameManager`, `BladeTimeController` |
| 다른 스크립트에서 `X.Instance.함수()` 호출 | `AnimalBall` → `MergeGameManager.Instance.MergeBall()` | `Fruit` → `GameManager.Instance.OnCut()` |
| `Update`에서 요청 플래그만 세우고 `FixedUpdate`에서 `AddForce` | `GolfBall.Shoot()`, `ForceModeLauncher` | `Fruit.Launch()` |
| `OnCollisionEnter` + `LayerMask` 검사 (`LayerMaskExtensions.Contains`) | `AnimalBall`, Utils `LayerMaskExtensions` | `Fruit` 바닥 충돌 |
| 오브젝트 풀: `IObjectPoolItem` 구현 + `ObjectPoolManager.Instance.GetObjectOrNull(키)` → 위치 지정 → `SetActive(true)` | FPS `ParticleEffect`, `HitEffectController` | 과일, 과즙 파티클 (조각은 매번 모양이 달라 `Instantiate`/`Destroy`) |
| `SetActive(false)` / `SetParent(null)` | `MergeGameManager.MergeBall()`, `AnimalBall.Drop()` | 슬로우 중 조각 숨기기·보이기 |
| `[Header]`, `public` 설정값, `{ get; private set; }` 프로퍼티 | `GolfBall`, `AnimalBall` | 모든 스크립트 |
| `QuestButtons.Create(버튼, 이름, 키보드폴백)` 입력 | XR `BoothRound`, `ImpulseLauncher` | `BladeTimeController` |
| 게임오버 시 켜고 끌 오브젝트 배열 | `MergeGameManager.GameOver()` | `GameManager` 패널·레이 전환 |

**작성 규칙**
- 직접 만드는 스크립트는 **7개**다. 이미 만들어 둔 스크립트는 **수정 없이 복사**해 쓴다.
  - XR 수업: `QuestButton`, `QuestButtons`, `SceneTimestep`
  - FPS Game: `IObjectPoolItem`, `ObjectPoolManager`, `ParticleEffect` (네임스페이스 `Study3D.FpsGame` 그대로, `using`으로 가져옴)
  - Utils: `LayerMaskExtensions`
- 네임스페이스는 `TimeSlasher` 하나로 통일한다.
- 수업처럼 **한 줄 한 줄 무엇을 하는지 한글 주석**을 단다. 조건은 `== false`처럼 풀어 쓴다.
- 이번 프로젝트에서는 쓰지 않는 것: 상태 머신(FSM), 새 인터페이스·상속, `event Action`, ScriptableObject 테이블. 3일 일정에서는 오히려 코드가 길어진다. 상태는 `enum` 하나, UI는 매 프레임 값을 읽는 방식으로 충분하다. 인터페이스는 이미 있는 `IObjectPoolItem`만 구현한다.
- 칼 판정은 직접 계산하지 않고 Unity 물리 함수(`Raycast`, `OverlapCapsule`)를 쓴다. 단, 과일은 과일 전용 물리 씬에 있으므로 `Physics.` 대신 `FruitWorld.Instance.FruitPhysics.`로 부른다.
- 수학 공식이 필요한 부분은 **짧은 함수 하나로 따로 빼고** `// [수학] AI 작성` 주석을 단다. 나머지 코드는 그 함수를 부르기만 한다.

### 레이어와 충돌

| 레이어 | 용도 | 충돌 대상 |
| --- | --- | --- |
| `FruitRising` | 발사 직후 과일 (바닥 아래 → 바닥 위) | 없음 |
| `Fruit` | 바닥 위로 올라온 과일, 모든 조각 | `Floor`만 |
| `Floor` | 바닥 | `Fruit` |

Project Settings → Physics → Layer Collision Matrix에서 위 표대로 체크한다. 과일끼리는 충돌하지 않는다.

### 풀 프리팹 (`ObjectPoolManager`의 `objectPoolDatas`에 등록)

| 키 | 프리팹 | 구성 | ExpandSize |
| --- | --- | --- | --- |
| `Apple`, `Orange` … | Fruit_Apple … | 모델, Rigidbody, SphereCollider, `Fruit` (`isPiece` 끔) | 6 |
| `Juice` | Juice | ParticleSystem (Play On Awake 켬, Loop 끔), FPS의 `ParticleEffect` | 8 |

꺼내는 방법은 FPS `HitEffectController`와 같다: `GetObjectOrNull(키)` → 위치 지정 → `SetActive(true)`. 풀에 넣을 때는 `ObjectPoolManager`가 알아서 `SetActive(false)` 한다.

### 무기 (컨트롤러 자식, 잡기 없음)

무기는 집어 드는 대신 **양손 컨트롤러의 자식으로 미리 붙여두고, 고른 무기만 켠다.** `GameManager`의 `longSwordObjects`에 Sword_Long, `dualSwordObjects`에 Sword_Short_L·Sword_Short_R를 넣는다. Rigidbody·콜라이더·XRGrabInteractable은 필요 없다.

```
Sword_Long
 ├ Model              (콜라이더 지우기)
 └ Blade (Blade.cs)   haptic = 그 손 컨트롤러의 HapticImpulsePlayer
     ├ BladeBase        칼날 시작점 (빈 오브젝트)
     └ BladeTip         칼날 끝점 (빈 오브젝트)
```

- 전시대 진열 모델은 레이로 가리키고 트리거(선택)를 누르면 `XRSimpleInteractable`의 Select Entered 이벤트가 불린다. 게임 중에는 `GameManager`가 무기 변경을 무시한다.
- 칼 모델의 **로컬 X축(빨간 화살표)이 칼날 면에 수직**이 되도록 맞춘다. 칼이 거의 움직이지 않을 때 이 방향으로 자른다.

## 4. 스크립트별 설계

### 4-0. `FruitWorld` — 과일 전용 물리 세계 (슬로우의 핵심)

`Time.timeScale`을 바꾸면 플레이어 손과 칼까지 느려진다. 그래서 **과일만 들어 있는 물리 세계를 따로 만들고, 그 세계의 시간만 느리게 흘려준다.** 과일 세계 안에서는 중력·튕김·마찰이 평소와 완전히 똑같이 계산되고, 속도만 느려진다. 과일에만 `timeScale`을 건 것과 같다.

```csharp
namespace TimeSlasher
{
    public class FruitWorld : MonoBehaviour
    {
        public static FruitWorld Instance;

        [Header("과일 세계로 옮길 부모 (과일 풀, 조각, 바닥 콜라이더가 들어감)")]
        public Transform root;

        public Transform Root => root;
        public PhysicsScene FruitPhysics { get; private set; }

        private void Awake()
        {
            if (Instance == null) Instance = this;
            else { Destroy(gameObject); return; }

            // 1. 물리 연산을 따로 하는 씬을 하나 만든다
            Scene fruitScene = SceneManager.CreateScene("FruitPhysics",
                new CreateSceneParameters(LocalPhysicsMode.Physics3D));
            FruitPhysics = fruitScene.GetPhysicsScene();

            // 2. 과일 부모(FruitRoot)를 그 씬으로 옮긴다. 이후 이 아래에 생기는 건 전부 과일 세계 소속
            SceneManager.MoveGameObjectToScene(root.gameObject, fruitScene);
        }

        private void FixedUpdate()
        {
            // 3. 과일 세계를 "실제 시간 × 배율"만큼만 진행 (평소 1배, 슬로우 0.25배)
            FruitPhysics.Simulate(Time.fixedDeltaTime * BladeTimeController.Instance.Scale);
        }
    }
}
```

- 이 씬은 Unity가 자동으로 진행시키지 않는다. `FixedUpdate`에서 `Simulate`를 불러야만 시간이 흐른다.
- `Awake`에서 씬을 만들기 때문에, `ObjectPoolManager.Start`에서 풀을 만들 때는 이미 `FruitRoot`가 과일 세계에 있다. 풀 데이터의 `Parent`를 `FruitRoot`로 지정하면 과일이 처음부터 과일 세계에 생성된다 (풀 코드 수정 없음).
- `OnCollisionEnter`는 과일 세계 안에서도 그대로 호출된다.

### 4-1. `BladeTimeController` — 블레이드 타임 (타임 슬로우)

| 인스펙터 값 | 기본값 | 설명 |
| --- | --- | --- |
| `slowScale` | 0.25 | 슬로우 중 과일 속도 배율 |
| `maxSlowSeconds` | 3 | 가득 찬 게이지로 버티는 시간 (실제 시간) |
| `minGaugeToStart` | 0.25 | 이 이상이어야 발동 |
| `slowVolume` | — | 비네팅 Volume |

```csharp
namespace TimeSlasher
{
    public class BladeTimeController : MonoBehaviour
    {
        // 약식 싱글톤 (MergeGameManager와 같은 방식)
        public static BladeTimeController Instance;

        [Header("Slow Settings")]
        public float slowScale = 0.25f;
        public float maxSlowSeconds = 3f;
        public float minGaugeToStart = 0.25f;
        public Volume slowVolume;

        // 밖에서는 읽기만, 바꾸는 건 나만
        public float Scale { get; private set; } = 1f;   // 과일 세계가 흐르는 속도 (FruitWorld가 읽음)
        public bool IsSlow { get; private set; } = false;
        public float Gauge { get; private set; } = 0f;   // 0 ~ 1

        private InputAction slowAction;

        private void Awake()
        {
            if (Instance == null) Instance = this;
            else Destroy(gameObject);
        }

        private void OnEnable()
        {
            // A 버튼으로 액션을 만들고, X 버튼과 키보드 F4를 추가로 묶어줍니다
            slowAction = QuestButtons.Create(QuestButton.A, "BladeTime", "<Keyboard>/f4");
            slowAction.AddBinding(QuestButtons.Path(QuestButton.X));
            slowAction.Enable();
        }

        private void OnDisable()
        {
            slowAction.Disable();
            slowAction.Dispose();
        }

        private void Update()
        {
            // 게임 중이 아니면 아무것도 하지 않음
            if (GameManager.Instance.IsPlaying == false) return;

            bool pressed = slowAction.IsPressed();

            // 1. 슬로우가 아니고, 키를 눌렀고, 게이지가 충분하면 → 슬로우 시작
            if (IsSlow == false && pressed && Gauge >= minGaugeToStart)
            {
                StartSlow();
            }

            // 2. 슬로우 중이면 게이지를 빠르게 깎고, 키를 떼거나 게이지가 바닥나면 → 끝
            if (IsSlow)
            {
                Gauge -= Time.deltaTime / maxSlowSeconds;
                if (pressed == false || Gauge <= 0f) EndSlow();
            }
        }

        private void StartSlow()
        {
            IsSlow = true;
            Scale = slowScale;
            slowVolume.weight = 1f;   // 파란 비네팅 켜기
        }

        private void EndSlow()
        {
            IsSlow = false;
            Scale = 1f;
            slowVolume.weight = 0f;
            Gauge = Mathf.Max(0f, Gauge);
            // 슬로우 동안 벤 과일을 한 번에 갈라지게 함
            GameManager.Instance.ReleaseAll();
        }

        // 과일을 벨 때 GameManager가 호출 (슬로우 중엔 충전 안 함)
        public void AddGauge(float amount)
        {
            if (IsSlow) return;
            Gauge = Mathf.Min(1f, Gauge + amount);
        }

        // 게임 시작·게임 오버 때 GameManager가 호출
        public void ResetGauge() { Gauge = 0f; }
        public void ForceEnd() { if (IsSlow) EndSlow(); }
    }
}
```

### 4-2. `Fruit` — 과일과 조각 공용 (`IObjectPoolItem` 구현)

**과일 프리팹과 조각 프리팹이 같은 스크립트를 쓴다.** 조각은 `isPiece = true`일 뿐이다. 과일은 풀에서 꺼내 재사용하고, 조각은 만들고 지운다.

| 인스펙터 값 | 설명 |
| --- | --- |
| `isPiece` | 조각 프리팹이면 체크 (점수 없음, 놓침 판정 없음, 바닥에 닿고 2초 뒤 삭제) |
| `piecePrefab` | 잘랐을 때 만들 조각 프리팹 (FruitPiece) |
| `floorMask` | 바닥 레이어 (`Floor`) |
| `crossSectionMat` | 단면(과육) 머티리얼 |
| `minPieceSize` | 0.03 — 이보다 작은 조각은 벨 수 없음 |
| `killY` | −1 — 이 높이 아래로 내려가면 즉시 `Remove()`. 발사 높이(−0.3)보다 낮아야 함 |

| 내부 변수 | 설명 |
| --- | --- |
| `cutCount` | 이 과일 계열이 잘린 횟수 (최대 3) |
| `noCutTime` | 0보다 크면 베이지 않음. 벤 직후와 생긴 직후 0.2초 |
| `scored`, `missed` | 이미 점수를 줬는지, 이미 놓침 처리했는지 |
| `touchedFloor` | 바닥에 한 번이라도 닿았는지. 닿은 뒤 2초가 지나면 `Remove()` |
| `reserved` | 슬로우 중 베여서 일괄 절단을 기다리는 중 |
| `hiddenPieces` | 슬로우 중 미리 잘라 숨겨둔 조각 목록 (`List<Fruit>`) |

**⓪ 풀 아이템 구현과 초기화 (FPS `ParticleEffect`와 같은 방식)**

```csharp
public class Fruit : MonoBehaviour, IObjectPoolItem
{
    // IObjectPoolItem 구현
    public string Key { get; set; }
    public GameObject GameObject => gameObject;

    // 풀에서 꺼낼 때마다 호출. 재사용되는 개체라 이전 상태를 전부 지워줍니다
    public void Init()
    {
        cutCount = 0;
        noCutTime = isPiece ? 0.2f : 0f;
        scored = false; missed = false; reserved = false; touchedFloor = false;
        lifeTime = 2f;
        hiddenPieces.Clear();
        body.linearVelocity = Vector3.zero;
        body.angularVelocity = Vector3.zero;
        // 과일은 바닥 아래에서 출발하므로 아무것과도 안 부딪히는 레이어로 시작
        gameObject.layer = isPiece ? fruitLayer : risingLayer;
        HideSlashLines();
    }

    // 화면에서 없앨 때는 항상 이 함수를 부름 (베임, 놓친 뒤 2초, 조각 수명 끝, 게임 오버)
    public void Remove()
    {
        // 숨겨둔 조각이 있으면 같이 없앰
        foreach (Fruit piece in hiddenPieces) piece.Remove();
        hiddenPieces.Clear();

        if (isPiece)
        {
            // 조각은 자를 때마다 모양이 달라 재사용하지 않고 삭제
            // 메시는 새로 만든 것이라 직접 지워야 메모리가 안 샘
            Destroy(meshFilter.mesh);
            Destroy(gameObject);
        }
        else
        {
            // 과일은 모양이 늘 같으므로 풀로 돌려보내 재사용
            ReturnToPool();
        }
    }

    // IObjectPoolItem 구현 (과일만 사용)
    public void ReturnToPool()
    {
        ObjectPoolManager.Instance.ReturnToPool(this);   // 여기서 SetActive(false)
    }
}
```

- **조각**은 자를 때마다 모양이 달라 풀에 넣지 않는다. `Instantiate`로 만들고, 바닥에 닿고 2초 뒤 `Destroy`로 지운다. 만들 때도 `Init()`을 불러 같은 초기값으로 시작한다.

### 4-3. `Blade` — 칼 판정

| 인스펙터 값 | 기본값 | 설명 |
| --- | --- | --- |
| `bladeBase`, `bladeTip` | — | 칼날 시작점, 끝점 |
| `bladeRadius` | 0.02 | 칼날 두께 (반지름) |
| `fruitMask` | Fruit | 판정할 레이어 |

판정은 두 가지를 매 프레임 둘 다 한다. 과일은 과일 전용 물리 씬에 있으므로 **`Physics.` 대신 `FruitWorld.Instance.FruitPhysics.`** 로 검사한다.
- **휘두를 때**: 칼날 위 5개 점이 지난 프레임 위치 → 이번 프레임 위치로 이동한 선을 `Raycast`로 검사한다. 빠르게 휘둘러도 과일을 지나치지 않는다.
- **가만히 대고 있을 때**: 칼날을 캡슐로 보고 `OverlapCapsule`로 닿아 있는 과일을 찾는다.

```csharp
private Collider[] touching = new Collider[16];   // OverlapCapsule 결과를 담을 배열 (미리 만들어 둠)

void LateUpdate()        // XRI가 칼을 손 위치로 옮긴 뒤에 검사
{
    PhysicsScene fruitPhysics = FruitWorld.Instance.FruitPhysics;

    // 휘두를 때: 지난 위치 → 지금 위치로 선을 쏴서 과일이 걸리는지
    for (int i = 0; i < 5; i++)
    {
        float t = i / 4f;
        Vector3 from = Vector3.Lerp(prevBase, prevTip, t);
        Vector3 to   = Vector3.Lerp(bladeBase.position, bladeTip.position, t);
        Vector3 dir  = to - from;
        float dist   = dir.magnitude;
        if (dist < 0.0001f) continue;              // 안 움직였으면 건너뜀

        if (fruitPhysics.Raycast(from, dir / dist, out RaycastHit hit, dist, fruitMask))
            TryCut(hit.collider, hit.point);
    }

    // 가만히 대고 있을 때: 칼날 캡슐 안에 들어온 과일
    int count = fruitPhysics.OverlapCapsule(bladeBase.position, bladeTip.position, bladeRadius, touching, fruitMask);
    for (int i = 0; i < count; i++)
        TryCut(touching[i], ClosestPointOnBlade(touching[i].transform.position));

    SavePrevious();
}

void TryCut(Collider col, Vector3 point)
{
    Fruit fruit = col.GetComponent<Fruit>();
    if (fruit == null) return;
    if (fruit.Cut(point, GetCutNormal()) == false) return;   // 실제로 베였을 때만
    if (haptic != null) haptic.SendHapticImpulse(0.6f, 0.05f);
}
```

- **같은 과일이 한 프레임에 여러 번 베이는 문제**는 `Fruit`의 `noCutTime`(0.2초)이 막는다. 칼 쪽에서 따로 목록을 관리하지 않는다.
- **켜짐과 진동**: 칼은 컨트롤러 자식이라 켜져 있는 동안만 판정한다 (`OnEnable`에서 지난 위치를 지금 위치로 초기화). 진동할 손의 `HapticImpulsePlayer`는 인스펙터에서 넣는다.

### 4-4. `FruitSpawner` — 과일 발사

| 인스펙터 값 | 기본값 | 설명 |
| --- | --- | --- |
| `fruitKeys` | Apple, Orange … | 꺼낼 과일 풀 키 배열 (랜덤 선택) |
| `player` | — | 플레이어 기준 위치 (XR Origin) |
| `pattern` | Mixed | Rise / Toss / Mixed(Rise+Toss 반반) |
| `launchY` | −0.5 | 바닥 발사 높이 (바닥 아래) |
| `rise` (LaunchSettings) | 거리 0.5~0.85, 최고점 1.3~1.8, 좌우 −35~35° | **Rise** 가까이에서 수직 발사. 거리는 긴 검 기준 |
| `toss` (LaunchSettings) | 거리 2.0~3.0, 최고점 1.1~1.7, 좌우 −30~30° | **Toss** 멀리서 발사, 최고점은 타격 존 |
| `hitZoneMinDistance` / `hitZoneMaxDistance` | 0.5 / 0.85 | 타격 존: Toss 최고점의 플레이어 앞 거리 (긴 검 기준) |
| `hitZoneHalfWidth` | 0.45 | 타격 존 좌우 폭의 절반 |
| `dualDistanceScale` | 0.8 | 쌍검일 때 Rise 거리·타격 존 거리·폭에 곱함 (긴 검 날 0.71m, 쌍검 날 0.48m, 팔 길이 포함 리치 비율) |
| `startInterval` / `endInterval` | 2.0 / 0.7 | 발사 간격 (처음 → 최대 난이도) |
| `maxCount` | 4 | 한 번에 최대 발사 개수 |
| `rampSeconds` | 90 | 최대 난이도까지 걸리는 시간 |

```csharp
void Update()
{
    if (GameManager.Instance.IsPlaying == false) return;

    playTime += Time.deltaTime;
    timer -= Time.deltaTime * BladeTimeController.Instance.Scale;     // 슬로우 중엔 발사도 느리게
    if (timer > 0f) return;

    float level = Mathf.Clamp01(playTime / rampSeconds);   // 0 → 1 난이도
    timer = Mathf.Lerp(startInterval, endInterval, level);
    int count = Random.Range(1, 1 + Mathf.RoundToInt(Mathf.Lerp(1, maxCount, level)));
    for (int i = 0; i < count; i++) SpawnOne();
}

void SpawnOne()
{
    // 1. 풀에서 랜덤 과일 하나 꺼내기
    string key = fruitKeys[Random.Range(0, fruitKeys.Length)];
    Fruit fruit = ObjectPoolManager.Instance.GetObjectOrNull(key) as Fruit;
    if (fruit == null) return;

    // 2. 위치·회전 정하고 상태 초기화 후 켜기
    Vector3 pos = GetLaunchPosition(tossMinDistance, tossMaxDistance, tossSideAngle);   // 패턴별 거리
    fruit.transform.SetPositionAndRotation(pos, Random.rotation);
    fruit.Init();
    fruit.gameObject.SetActive(true);

    // 3. 발사 요청 (힘은 Fruit의 FixedUpdate에서 줌)
    Vector3 velocity = GetVelocityToApex(pos, GetHitZonePosition());   // 타격 존에서 최고점
    fruit.Launch(velocity);
}
```

**발사 패턴** (`LaunchPattern` enum, 인스펙터 `pattern`)
- `Rise`: `riseDistance`(0.6~1.0m) 가까이 바닥 아래에서 수직으로 올라갔다 그대로 떨어짐
- `Toss`: `tossDistance`(2~3m) 멀리 바닥 아래에서 솟아올라 **타격 존에서 최고점**이 되도록 플레이어 쪽으로 토스
- `Pitch`: (확장 목표) 정면 `pitchDistance`(12m) 앞, 높이 `pitchY`에서 던져 `flightSeconds`초 뒤 같은 타격 존에 도착. 못 베면 플레이어 뒤 바닥에 떨어질 때 놓침 처리
- `Mixed` (기본): 과일마다 Rise와 Toss 반반

**수학 함수 — `// [수학] AI 작성`**
- `GetHitZonePosition()`: 타격 존 안 랜덤 점 (Toss·Pitch가 같이 씀)
- `GetVelocityToApex(start, apex)`: `vy = √(2·g·높이차)`, `t = vy/g`, 수평 속도 = 수평 거리 / t → apex에서 최고점 (Rise는 apex가 바로 위라 수직)
- `GetLaunchPosition(min, max, angle)`: 플레이어 정면 기준 거리·각도 랜덤 위치 (Rise·Toss가 각자 거리로 부름)
- `GetPitchPosition()`: 투구 시작점
- `GetVelocityToTarget(start, target, t)`: t초 뒤 target에 도착하는 초속도 `v = (target − start)/t − ½·g·t`

### 4-5. `GameManager` — 게임 상태, 점수, 콤보, 목숨

```csharp
public enum GameState { Lobby, Playing, GameOver }

public class GameManager : MonoBehaviour
{
    public static GameManager Instance;
    public GameState State = GameState.Lobby;
    public bool IsPlaying => State == GameState.Playing;

    public int Score, BestScore, Lives = 3, Combo;
    float comboTimer;
    List<Fruit> reserved = new List<Fruit>();

    void Awake()
    {
        // 약식 싱글톤: 하나만 남기고 나머지는 삭제
        if (Instance == null) Instance = this;
        else Destroy(gameObject);

        BestScore = PlayerPrefs.GetInt("Best", 0);
    }

    public void StartGame()                 // 시작 버튼 OnClick에 연결
    {
        Score = 0; Lives = 3; Combo = 0; BladeTimeController.Instance.ResetGauge();
        State = GameState.Playing;
        SetRays(false);                     // 플레이 중엔 레이 숨김
    }

    public void OnCut(bool firstCut)
    {
        Combo++;
        comboTimer = 2f;
        if (firstCut == false) return;      // 조각 베기는 콤보만

        int points = Mathf.RoundToInt(10 * ComboMultiplier());
        if (BladeTimeController.Instance.IsSlow) points *= 2;
        Score += points;
        BladeTimeController.Instance.AddGauge(0.1f);
    }

    public void OnMiss()
    {
        Lives--; Combo = 0;
        if (Lives <= 0) GameOver();
    }

    public void Reserve(Fruit f)   { reserved.Add(f); }
    public void Unreserve(Fruit f) { reserved.Remove(f); }

    public void ReleaseAll()                // 슬로우 끝: 같은 프레임에 전부 갈라짐
    {
        int count = reserved.Count;
        foreach (Fruit f in reserved) if (f != null) f.Release();
        reserved.Clear();
        if (count > 0) PlayBigSlash(count);  // 큰 효과음 1회, 양손 진동, 플래시, "×N SLASH"
    }

    float ComboMultiplier()
    {
        if (Combo >= 20) return 3f;
        if (Combo >= 10) return 2f;
        if (Combo >= 5)  return 1.5f;
        return 1f;
    }

    void Update()
    {
        if (IsPlaying == false) return;
        comboTimer -= Time.deltaTime * BladeTimeController.Instance.Scale;   // 과일 시간 기준
        if (comboTimer <= 0f) Combo = 0;
    }

    void GameOver()
    {
        State = GameState.GameOver;
        BladeTimeController.Instance.ForceEnd();
        reserved.Clear();
        // 화면에 남은 과일·조각을 전부 풀로 돌려보냄 (켜져 있는 것만 찾아짐)
        foreach (Fruit f in FindObjectsByType<Fruit>(FindObjectsSortMode.None)) f.Remove();
        if (Score > BestScore) { BestScore = Score; PlayerPrefs.SetInt("Best", BestScore); }
        SetRays(true);
    }
}
```

- `SetRays(bool)`: 인스펙터에 넣어둔 양손 레이 오브젝트를 켜고 끈다.
- `PlayBigSlash(count)`: `AudioSource.PlayOneShot`, 양손 `HapticImpulsePlayer.SendHapticImpulse`, 플래시 이미지 표시를 `GameUI`에 요청한다.
- 게임 오버 화면의 재시작 버튼은 `StartGame()`을 그대로 부른다. 게임 중이 아니면 전시대로 무기를 바꿀 수 있다. 종료 버튼은 `QuitGame()`.

### 4-6. `GameUI` — 화면 표시

값을 **매 프레임 읽어서 그대로 표시**하는 단순한 방식이다. 화면은 `GameUIBuilder`가 만들고, `GameUI`에는 만들어진 오브젝트를 연결만 한다.

| 구역 | 위치 | 누를 수 있나 | 내용 |
| --- | --- | --- | --- |
| World UI | 플레이어 정면 2m, World Space + `TrackedDeviceGraphicRaycaster` | 레이 + 트리거 | LobbyPanel(제목, 무기, 안내, 시작), GameOverPanel(점수, 최고 점수, 재시작, 종료) |
| HUD UI | Main Camera 자식, 1m 앞 World Space, Raycaster 없음 | 못 누름 | 목숨 아이콘 3개(왼쪽 위), 점수·콤보(오른쪽 위), 블레이드 타임 게이지(아래 가운데), 플래시·"xN SLASH"(가운데) |

- Screen Space Overlay는 헤드셋에 그려지지 않아서 HUD를 카메라 자식 World Space 판으로 만든다.
- 목숨은 `lifeIcons[i].SetActive(i < Lives)`로 잃을 때마다 하나씩 꺼진다.
- 게이지는 `GaugeFill`의 피벗을 왼쪽 끝에 두고 `localScale.x = Gauge`로 줄인다 (스프라이트 없이 동작).
- 버튼 OnClick: 시작·재시작 → `GameManager.StartGame()`, 종료 → `GameManager.QuitGame()` (에디터에선 플레이 중지).

```csharp
void Update()
{
    GameManager gm = GameManager.Instance;
    lobbyPanel.SetActive(gm.State == GameState.Lobby);
    gameOverPanel.SetActive(gm.State == GameState.GameOver);
    hudPanel.SetActive(gm.State == GameState.Playing);

    for (int i = 0; i < lifeIcons.Length; i++) lifeIcons[i].SetActive(i < gm.Lives);
    scoreText.text = $"{gm.Score}";
    gaugeFill.localScale = new Vector3(BladeTimeController.Instance.Gauge, 1f, 1f);
}
```

### 4-7. `GameUIBuilder` — 화면 조립 에디터 도구 (수업 UIBuilderPrompt 구조)

- `90. Tools/GameUIBuilder.cs`. 빈 GameObject에 붙이고 컴포넌트 우클릭 **1. Build UI / 2. Clear UI**.
- 구현은 `#if UNITY_EDITOR` 안 (필드는 직렬화가 어긋나지 않게 밖에 둠). 도우미 `NewUI / NewPanel / NewText / NewButton / Stretch` + 위치용 `Place`.
- `font`(NotoSansKR-Regular SDF), `headCamera`(HUD를 붙일 카메라)를 인스펙터에 넣는다.
- 화면만 만들고 게임 스크립트는 연결하지 않는다. 연결은 인스펙터에서 한다.
- 수업 프롬프트와 다른 점: Overlay 대신 World Space (VR이라), `GraphicRaycaster` 대신 `TrackedDeviceGraphicRaycaster`, HUD에는 Raycaster 없음.

## 6. 주의할 점

- 과일 모델은 **닫힌 로우폴리 메시**를 쓰고, 임포트 설정에서 **Read/Write Enabled**를 켠다. 안 켜면 빌드에서 절단이 안 된다.
- 조각을 지울 때는 `Destroy(gameObject)`만으로는 부족하다. 잘라서 만든 메시는 따로 `Destroy(mesh)` 해야 메모리가 안 샌다 (`Fruit.Remove`).
- 풀에서 꺼낸 과일은 이전 상태가 남아 있다. 꺼낼 때 반드시 `Init()`을 호출한다 (속도, 레이어, 점수 여부, 숨겨둔 조각 목록 초기화).
- 과일을 없앨 때 숨겨둔 조각도 함께 지운다. 꺼져 있는 조각은 `FindObjectsByType`로 찾아지지 않아서, 안 그러면 씬에 계속 남는다.
- 과일·조각을 없앨 때는 `Destroy`나 `ReturnToPool`을 직접 부르지 말고 항상 `Remove()`를 부른다. 과일인지 조각인지에 따라 알아서 처리한다.
- 과일·조각 Rigidbody: `Use Gravity` **켬** (과일 세계에서 평소처럼 중력을 받음), `Linear Damping` 0. `Interpolate`는 직접 진행시키는 물리 씬에서는 적용되지 않는다. 물리 주기(1/72)가 화면 주사율과 같아 체감 차이는 거의 없다.
- 바닥은 얇은 Plane이 아니라 **두꺼운 BoxCollider**로 만든다. 떨어지는 과일이 뚫고 지나가지 않게 하기 위해서다.
- 과일·조각·바닥 콜라이더는 반드시 `FruitRoot` 아래(과일 물리 씬)에 있어야 서로 부딪힌다. 칼 판정도 `Physics.`가 아니라 `FruitWorld.Instance.FruitPhysics.`로 해야 과일이 찾아진다.
- `FruitRoot`는 씬 최상위 오브젝트여야 `MoveGameObjectToScene`으로 옮길 수 있다.
- 예약 과일은 어떤 이유로 없어지든 `Unreserve`로 목록에서 빼야 한다. 안 빼면 풀에서 다시 꺼내 쓰는 중인 다른 과일이 `ReleaseAll`에서 엉뚱하게 갈라진다. 그래서 `Fruit.Remove()` 안에서 `Unreserve`를 부르고, `ReleaseAll`은 목록 복사본으로 돈다.
- `Fruit.Remove()`는 같은 프레임에 두 번 불려도 한 번만 처리한다 (`removed` 플래그). 풀에 같은 과일이 두 번 들어가면 한 과일이 두 번 꺼내진다.
- `Fruit.Cut()`은 실제로 베였을 때만 `true`를 돌려준다. 평면이 메시를 안 지나가면 점수·콤보·진동이 없다.

## 7. VR 없이 테스트하기 (XR Interaction Simulator)

플레이어 조작 코드를 새로 만들지 않고, **XRI 기본 리그와 시뮬레이터를 그대로 쓴다.** 이동만 꺼서 제자리 플레이로 만든다.
테스트 씬은 `Assets/00. SlashTime/Test.unity`이고, 값은 씬·프리팹 인스펙터와 스크립트에서 직접 고친다. (씬을 처음 만들 때 쓴 에디터 생성 스크립트는 지웠다.)

| 씬 구성 | 내용 |
| --- | --- |
| XR Origin (XR Rig) | XRI Starter Assets 프리팹. 자식 `Locomotion`(이동·회전·텔레포트)만 꺼서 제자리 플레이 |
| XR Interaction Simulator | XRI 샘플 프리팹. 마우스·키보드로 머리와 양손 컨트롤러를 움직임 (조작키는 화면 안내 참고) |
| EventSystem | `XRUIInputModule` (레이로 UI 클릭) |
| 칼 | 검은 Cube. 오른손에 Sword_Long(1.0m), 양손에 Sword_Short(0.55m). `Blade`의 `haptic`은 각 컨트롤러의 HapticImpulsePlayer |
| WeaponRack | 플레이어 오른쪽 탁자. 앞쪽 긴 칼 = 한손검, 뒤쪽 짧은 칼 2자루 = 쌍검. `XRSimpleInteractable`의 Select Entered → `GameManager.SelectLongSword / SelectDualSwords` |
| World UI / HUD UI | `GameUIBuilder`로 만든 화면 (4-6, 4-7). `Systems/GameUI`에 연결, 버튼 OnClick → `StartGame / QuitGame` |
| FruitRoot | FloorCollider (Floor 레이어, 두께 0.5m) |

- Play → 오른손 레이로 정면 시작 버튼을 가리키고 트리거 → 게임 시작. 버튼 클릭은 XR 수업 투어 씬(5000-xr `TourGuide` 안내판 버튼)과 같은 방식이다.

- 칼의 `Blade.drawDebug`를 켜면 Scene 뷰에 자르는 방향(하늘색 선)이 그려진다.
- 시뮬레이터에서는 진동 기능 조회 경고(`Failed to get haptic capabilities of XRSimulatedController`)가 뜨지만 무시해도 된다.
